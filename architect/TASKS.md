# Macro-Task: Implement a TODO desktop application in Python that persists each list as a separate markdown file. MacOS will be the primary target OS.
**Testing Framework:** pytest (standard for Python; `python3 -m pytest`).

Architecture (each list = one `.md` file under a data dir, default `~/.todo-md-app/lists/`):
- `src/todo_md/models.py` — domain: `TodoItem` (text, done, created_ts), `TodoList` (name, items; add/toggle/remove/rename).
- `src/todo_md/storage.py` — `MarkdownListStore`: read/write each `TodoList` as `<name>.md` with GFM checkboxes (`- [ ]`, `- [x]`), robust parse (headers, blank lines, non-checkbox lines preserved or ignored deterministically), atomic writes, no overwriting on conflict.
- `src/todo_md/app.py` — `TodoController` (UI-agnostic view-model: lists of lists, add list, add/toggle/remove item) + Tkinter `TodoApp` GUI wired to it (macOS native Tk).
- `src/todo_md/__main__.py` — entry point `python3 -m todo_md` launches the GUI.
- Tests live in `src/tests/`; GUI is never required in tests (controller is tested headless).
